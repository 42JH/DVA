# 한국어 통화 연습

휴대폰에서 Gemini Nano와 Gemma 4를 비교하거나 후속 개발을 이어갈 때는 [Android 실행 및 인계 안내](android-nano/README.md)를 먼저 보세요. 아래는 브라우저용 PoC의 실행 방법입니다.

Chrome 또는 Edge에서 마이크로 상대방 발화를 입력하면 Gemma 4 E2B Instruct가 답변 후보 3개를 추천합니다. 음성 인식과 답변 생성은 브라우저에서 처리됩니다.

## 실행

Node.js 22.12 이상과 WebGPU를 사용할 수 있는 브라우저가 필요합니다.

```powershell
cd kick/ai
npm ci
npm run dev
```

터미널에 표시된 localhost 주소를 열고 **모델 로드**를 누르세요. 처음에는 모델 약 2.34 GB를 내려받고 브라우저에 저장합니다. 이후 같은 주소와 브라우저 프로필에서 저장된 파일을 재사용합니다. 브라우저 저장 공간이 부족하거나 다운로드가 실패하면 모델을 직접 내려받고 **모델 파일 선택**에 지정할 수 있습니다.

**음성 인식 모델 준비 → 마이크 시작** 순서로 누르고 마이크 권한을 허용하세요. 기본 방식인 Whisper는 최초에 약 80 MB의 모델 파일이 필요합니다. 마이크에 “금요일 오후 두 시에 회의 가능하세요?”라고 말한 뒤 잠깐 쉬면 확정 자막이 표시되고, Gemma가 준비된 상태라면 추천 답변이 이어서 표시됩니다. 마이크와 Gemma는 어느 쪽이든 먼저 시작할 수 있습니다.

새 답변을 생성할 때마다 앱은 최신 발화부터 최대 8개, 총 800자까지 대화 기록을 모델에 전달합니다. “오후 세 시로 바꿔도 될까요?”처럼 앞 문장에 나온 요일을 생략해도 이 범위 안에서는 참고할 수 있습니다. 범위 밖 발화는 화면의 대화 기록에서 볼 수 있습니다.

**브라우저 한국어 음성 팩**을 선택하면 브라우저 내장 음성 인식과 임시 자막을 사용할 수 있습니다. 팩이 준비되지 않았다면 **한국어 음성 팩 설치**를 누르세요. Whisper는 발화가 끝난 뒤 자막을 표시합니다. 두 방식 모두 음성은 브라우저에서 처리합니다.

**시스템 프롬프트**에 “정중한 존댓말을 쓰고, 일정이 확실하지 않으면 확인한다고 답해 주세요” 같은 지시를 적을 수 있습니다. 다음 대화 분석과 Gemma 단독 테스트부터 적용됩니다.

추천 답변을 누르면 **나**의 발화로 기록합니다. **마이크 중지**는 현재 대화를 보존하고, **대화 초기화**는 마이크를 중지하고 대화 기록을 비웁니다. 브라우저에서 한국어 로컬 인식이 준비되지 않았을 때는 **상대방 발화 입력**을 사용할 수 있습니다. 음성 인식은 `processLocally`를 지원하고 한국어 팩을 사용할 수 있는 경우에만 시작합니다.

**Gemma 단독 테스트**에서도 한국어 응답 생성 및 중지를 확인할 수 있습니다. 두 화면이 같은 모델을 재사용합니다.

## 모델과 측정

- 모델은 [Gemma 4 E2B Instruct GPU 파일](https://huggingface.co/litert-community/gemma-4-E2B-it-litert-lm/blob/cccc664ea93091c52eeb7867ad4e5466357e14f3/gemma-4-E2B-it-gpu.litertlm)이며 Apache 2.0 라이선스입니다. 모델과 LiteRT-LM npm 버전을 고정합니다.
- 다운로드 시간은 네트워크 요청 시작부터 브라우저 저장 완료까지입니다. 초기화 시간은 준비된 파일로 엔진을 만들기까지이며 첫 로드 시 런타임 시작을 포함합니다.
- 첫 응답 조각은 브라우저가 화면에 표시할 첫 텍스트를 받은 시점이고, 첫 토큰은 SDK가 기록한 값입니다. 생성 속도도 SDK가 제공하는 값을 표시합니다. 대시(—)는 해당 실행에서 값이 없다는 뜻입니다.
- 런타임 파일은 설치된 npm 패키지에서 가져와 같은 서버에서 제공합니다. 저장된 모델을 재사용하거나 로컬 파일을 고르면 인터넷 연결 없이 추론할 수 있습니다.

## 검증

```powershell
npm run build
npm test
```

Playwright는 설치된 Chrome을 사용합니다. 모델 없이 WebGPU 미지원 상태를 확인할 수 있습니다. 실제 모델을 `kick/ai`에 두고 아래처럼 실행하면 한국어 생성·취소·재실행을 확인하고, 로컬 서버에서 모델을 받아 브라우저 저장소에 저장하고 다시 읽는 과정도 검사합니다.

```powershell
$env:GEMMA_MODEL_PATH = (Resolve-Path .\gemma-4-E2B-it-gpu.litertlm).Path
npm test
```

`GEMMA_TEST_DOWNLOAD=1`을 추가하면 캐시 테스트의 파일 출처가 Hugging Face로 바뀝니다. 브라우저에서 Hugging Face에 직접 연결한 첫 테스트는 제한 시간 내에 완료되지 않았습니다. 직접 내려받은 파일은 공식 SHA-256과 일치하는 것을 확인했습니다.

이 PC의 Chrome에서 외부 요청을 차단한 상태로 “네, 금요일 오후 3시에 회의 가능합니다.”를 생성했습니다. 해당 1회 실행의 모델 초기화는 약 4.70초, 첫 텍스트는 약 4.02초, 전체 생성은 약 4.56초였습니다. 반복 측정 전의 관측값이며 기기와 입력에 따라 달라집니다.

통화 연습 자동 테스트는 임시·확정 자막 이벤트를 재현하고, 실제 Gemma가 변경된 시간을 반영한 답변 후보 3개를 출력하는지 확인합니다. `WHISPER_TEST_WAV`에 한국어 회의 문장이 담긴 WAV를 지정하고 Whisper 파일을 `public/models/Xenova/whisper-base`에 두면, 외부 연결을 차단한 Chrome에서 가상 마이크로 음성을 넣는 테스트도 실행합니다.

고정 모델은 런타임 0.19.1 이상을 권장한다는 메시지를 출력합니다. 확인 당시 npm 안정 버전은 0.19.0이었으며, 이 버전에서 위 한국어 응답 생성을 확인했습니다.
