# 확정 경로 지연 줄이기 — 계획

상태: 계획(승인 전). 2026-11-04. 대상: 고객이 되읽기 확인 질문에 "네"라고 한 뒤 → 택배를 담고(확정) → AI가 담기 안내("더 보내실 택배 있으세요?")를 시작하기까지.

## 1. 지금 구간(실측 1건, 통화 142a57 — 표본 부족, §4에서 더 잰다)

| 시각(담기 기준) | 사건 | 구간 | 원인 |
|---|---|---|---|
| -2.7s | 고객 "네" 마지막 전사 | | |
| -2.3s | Live가 "네"를 위임(지시 위반) | | 고르는 답은 위임하지 않아야 함 |
| -1.6s | Decision confirm=yes → **확정 보류(G6)** | 발화 끝 800ms + Decision ~300ms | 같은 발화의 위임이 끝날 때까지 기다림 |
| -0.7s | 위임 종료 | 보류 ~0.9s | |
| 0.0s | 담기 | 확정 지연 700ms | 새 발화가 오면 취소하려는 대기 |
| 2.8s | N2(담기 안내) 송신 | **N2 대기 2.8s** | AI가 위임 결과("이렇게 진행하겠습니다")를 말하는 중 → 끝난 뒤 600ms |
| 5.4s | AI "추가로 발송하실 택배가 있으실까요?" | **N2→발화 2.6s** | Live가 알림에 반응하는 시간 |
| **합계 8.1s** | | | |

위임이 끼지 않아도 구조상 ~1.8s(발화 끝 0.8 + Decision 0.3 + 확정 지연 0.7) + N2 반응 시간이 든다.

## 2. 고칠 곳과 안

| # | 구간 | 안 | 안전 영향 | 기대 |
|---|---|---|---|---|
| P1 | 확정 지연 700ms | `commit_delay_ms` 700 → 300(설정) | "네, 근데…"처럼 말이 이어지면 취소하려는 대기 — 300ms 안에 다음 전사 조각이 오는지 실측으로 확인 | −0.4s |
| P2 | G6 보류(위임 대기) | **짧은 긍정 빠른 길**: 확인 발화가 짧은 긍정(정책 목록: "네·예·맞아요·네 맞아요·그대로 해 주세요" 등, 공백 제외 8자 이하)이고 Decision yes ≥ 0.9면 같은 발화 위임을 기다리지 않는다. 그 밖(정정이 섞일 수 있는 긴 발화)은 지금처럼 보류 | 정정이 섞인 발화는 길어 빠른 길에 들지 않음. 빠른 길로 확정된 뒤 같은 발화 위임이 값을 고치면 → 그 택배를 다시 열어 되읽기(기존 "수정" 경로) | −0.9s(위임 낀 경우) |
| P3 | Live의 "네" 위임 자체 | 업무 규칙에 예시로 못 박기("이대로 접수할까요?"의 '네·맞아요'는 맡기지 않는다). 관제 통계에 "도구 없는 위임" 비율 | 없음 | 위임 결과 발화("진행하겠습니다")가 사라져 P4 대기도 줄어듦 |
| P4 | N2 대기(AI 발화 끝 기다림) | ① 담기 사실을 **먼저 N1'(무음)으로** 즉시 넣고(Live가 지금 하는 말을 마친 뒤 이어서 말할 수 있게) ② N2는 지금처럼 조용해진 뒤 — 단 `notify_quiet_ms` 600 → 300. ③ 담기 직후 Live가 이미 "더 보내실 택배"를 물었으면 N2 생략(전사로 판정) | N1'만으로 Live가 말하는지는 **미확인** → 스파이크로 먼저 확인(§3) | −0.3~2s |
| P5 | N2→AI 발화 반응 | 알림 내용 최소화(담기 안내에 필요한 사실만: parcel_added·parcels, summary 제외) | 없음 | 측정 후 판단 |
| P6 | 발화 끝 800ms | 확인 대기 중에만 짧게(예 500ms) — "네"는 짧다 | 끝나지 않은 말을 끝났다고 볼 수 있음(긴 대답) → 확인 질문 답에만, 실측 후 | −0.3s |

목표: "네" 끝 → 담기 안내 시작 **P50 ≤ 3s**(지금 실측 8.1s, 1건).

## 3. 확인부터 할 것(추측 금지)
- **N1'(thinking.append)만으로 Live가 다음 말에 반영하는지**, commentary를 AI 발화 중에 보내면 어떻게 되는지 — 로컬 통화 2~3건으로 확인(관제 "N2→AI 발화"·"N2 대기").
- 짧은 긍정 뒤 300ms 안에 이어지는 말("네, 근데")이 실제로 얼마나 있는지 — 전사 조각 간격 분포.
