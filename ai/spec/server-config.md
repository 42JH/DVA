# 서버 설정 (`config/server.toml`)

GPT-Live 세션 바깥의 서버 동작 변수는 전부 여기에 둔다. 코드에 숫자·문구를 박지 않는다. 시작할 때 읽고 pydantic으로 검증해 잘못되면 기동을 멈춘다. 예:

- 통화: 동시 통화 상한(OpenAI 동시 세션 한도 안쪽, 넘으면 reject 코드), reject 상태 코드(300~699), 마무리 인사 후 끊기까지 조용함 기준·최대 대기(초), 상담원 전환 대상 SIP URI(`refer`), 웹훅 중복 제거 보관 시간
- 업무: 회사 이름(디포스트콜), 기본 요금(지금 가짜 3,500원), 접수 안내 문구, 마무리 인사 문구
- 진행 상태: `thinking.append` 최대 길이(500토큰 한도 안쪽)
- 백엔드 API: 요청 시간 제한, 조회 개수(주소는 환경변수 `BACKEND_API_URL`)
- 관제: SSE keepalive 간격, 끝난 통화를 화면에 남겨 두는 시간
- 고객 답 판별: 모델·추론 강도, 말이 멈췄다고 볼 시간(ms), 시간 제한, 넘기는 글자 수, 선택지 최대 개수
- 로그 수준

실제 항목은 `config/server.toml`의 주석과 `app/config.py`(검증 모델)가 기준이다.

모델·고객에게 나가는 진행 문구(단계별 할 일, 항목 묻는 말, 진행 상태 틀, 통화 정보, 판별 지시문)는 `prompts/flow.toml`에 둔다. 도구 설명·도구 오류 문장·판별 선택지 설명(모델용)은 코드(도구·단계 정의)에 둔다.
