# 미확정 결제 보관 만료와 휴대전화 입력 검증

## 범위와 순서

1. 5년이 지난 결제가 자동 복구에 계속 선택되고 폐기도 막히는 경로를 재현한다.
2. 만료된 요청은 새 승인·복구에서 제외하고, 실행 중인 작업의 기존 점유 시간만 보호한 뒤 FK 순서대로 폐기한다.
3. 해당 회귀 테스트를 통과한 뒤 결제 보관 변경을 커밋한다.
4. 고객·직원·PIN·주문 연락처와 고객 확인 입력을 숫자 문자열 11자리로 통일한다. 최종 주문 접수도 저장된 번호를 검사한다.
5. 전화번호 경계 테스트와 기존 정상 경로를 검증하고 별도 커밋한다.

## 결제 보관 계약

- 주문의 기존 보관 기준인 최초 완료·취소 시각, 미완료 주문의 생성 시각부터 달력 5년을 유지한다.
- 기한 안의 미확정 결제는 기존 키와 원본을 유지하며 복구한다. 타임아웃이나 404를 결제 실패로 간주하지 않는다.
- 5년이 지난 요청은 자동 복구 대상으로 선택하지 않고, 새로운 승인·조회 작업도 시작하지 않는다.
- 기존 승인 요청은 `approval_claimed_until`이 지나기 전까지 보호한다. 안내 발송은 기존 45초, 디버 전송은 기존 10초의 실행 구간을 보호한다.
- 보관이 끝났고 실제 실행 중인 요청이 없다면 상태값만으로 무기한 유예하지 않는다. 연결 통화의 FK 보호와 자식부터 삭제하는 트랜잭션 순서는 유지한다.
- 보관 만료 폐기는 결제 거절·취소·환불 처리가 아니다. 폐기 후 요청 원본은 복구할 수 없다.
- 테이블·컬럼·마이그레이션을 추가하지 않는다. 공개 조회의 기존 404 계약은 유지한다.

## 휴대전화 입력 계약

- 업무 전화번호 입력은 하이픈·공백 없는 숫자 문자열 정확히 11자리다. 숫자 타입, 줄바꿈, 9·10·12자리는 거절한다.
- 주문 수집 중 연락처 생략·null의 기존 의미는 유지하며, 값이 있으면 11자리로 검사한다.
- 신규 입력과 최종 접수에 적용한다. 기존 저장 데이터와 조회 응답을 일괄 변경하지 않는다.
- PBX 원문 발신번호의 국제 표기 수신·국내 표기 정규화 계약은 유지한다. 부분 검색어에도 완성 전화번호 검사를 적용하지 않는다.
- frontend·AI 소스는 이번 수정 범위에 포함하지 않는다. 호출자는 완성 번호를 11자리 문자열로 전송해야 한다.

## 검증

- 만료된 미확정 결제의 자동 선택 제외·새 점유 거절·자식 데이터 폐기.
- 보관 중인 미확정 결제의 키 보존과 복구 선택 유지.
- 활성 승인·안내·전송 작업과 연결 통화 보호, 점유 종료 후 폐기, 오래된 상태값의 무기한 유예 제거.
- 휴대전화 입력의 전체 호출 경로와 저장된 주문 최종 검증, PBX 국제 표기 및 부분 검색 회귀.
- lint·format·build·단위·격리 PostgreSQL 통합·배포 이미지·HTTPS/Nginx/SSE 검증.
