# 녹취 업로드 전 통화 표시

2026-11-02. 백엔드 통화 조회 변경과 프론트 인계 사항이다. AI·프론트 코드와 운영 설정은 변경하지 않았다.

## 확인된 지연 경로

- 통화 컨텍스트 수신으로 `call_sessions`가 생겨도 PBX의 `started_at`은 아직 null이다. 기존 목록은 이 값만 기간 조건에 사용하므로 기본 오늘 조회에서 해당 통화가 빠졌다.
- PBX 워커는 도착 순서 역전을 기다린 뒤 통화를 매칭하고 PBX 시각을 저장한 다음 녹취를 S3에 업로드한다. 목록 지연이 업로드와 같은 처리 구간에서 관찰될 수 있지만, 목록 SQL 자체는 녹취나 S3에 의존하지 않는다.
- 프론트 `callQueries.detail`은 `staleTime: Infinity`이며, 목록·상세 조회에 주기 갱신이 없다. 따라서 최초 조회 뒤 도착한 AI 분석·발화·녹취가 열려 있는 화면에 자동 반영되지 않는다.

## 백엔드 변경

기존 `GET /api/calls`와 `GET /api/calls/{id}`의 경로·필드·인증을 유지한다. `startedAt`은 PBX 시작 → AI 시작 → 수신 이벤트 시각, `endedAt`은 PBX 종료 → AI 종료 순서다. 기간 조건·정렬도 응답의 시작 시각과 같은 기준을 쓴다. 사용할 시각이 전혀 없는 과거 데이터는 null을 유지한다.

AI 분석·발화·처리 기록은 현재 받은 만큼 제공하고, 녹취 미수신이면 `recordings: []`다. 이후 같은 `callSessionSeq`에 PBX 시각·녹취가 연결되면 다음 조회에 추가된다. AI 분석 원본과 DB의 PBX 시각을 서로 덮어쓰지 않는다. 주문·종료 사유·미수신 분석 결과를 임의로 추정하지 않는다.

S3 업로드 워커의 지연·lease·실패 재시도·중복 방지와 비공개 재생 URL 계약은 그대로다. 신규 테이블·migration·상태 enum·API는 추가하지 않았다.

## 프론트 적용 사항

대상은 `frontend/src/features/call/api/callListApi.ts`, `hooks/useCallList.ts`, `api/callApi.ts`와 관련 테스트다. 다른 작성자의 코드 수정 승인을 요청했으며 이 백엔드 작업에서는 인계한다.

- 열린 목록과 검색 결과를 주기적으로 갱신해 새 통화를 반영한다. 새 분석이 없어도 통화를 표시하며 기존 '분석 전' 상태를 사용한다.
- 상세를 영구 캐시하지 않고, 분석·발화·처리 기록·녹취가 늦게 와도 갱신한다. 재생 중 유효한 서명 URL을 매번 새 URL로 바꾸어 오디오를 중단시키지 않는다. 만료 시 재발급과 재생 위치 복구는 유지한다.
- 녹취가 준비되지 않은 경우 대화·분석·처리 기록은 먼저 표시하고 재생만 준비 전 상태로 둔다. 없는 녹취를 성공·업로드 실패로 추정하지 않는다.
- AI→PBX→녹취 도착 순서, 반대 순서, 업로드 실패·재시도, 분석 미수신, 재생 중 갱신을 검증한다.

이 변경은 API가 현재 받은 데이터를 바로 조회할 수 있게 한다. 열려 있는 화면의 자동 갱신은 프론트 반영 후 확인하며, 운영 배포·실제 통화·실제 S3 업로드는 별도 검증 대상이다.

## 검증 결과

- 변경 전 코드로 PBX가 없는 수신 통화·AI 분석 통화가 기간 목록에서 빠지는 현상을 재현했다.
- `npm run check`: ESLint·Prettier·컴파일과 기본 113개·결제 모의 도구 21개 테스트 통과.
- 격리 로컬 PostgreSQL 18에 현재 migration 전체와 `infra/database/verify.sql`을 적용한 뒤 통화 분석 조회 14개, 녹취 파이프라인 11개, 통화 조회 24개, 고객 컨텍스트 12개, 분석 수신 8개, 이벤트 수신 20개, 총 89개 테스트가 통과했다.
- 녹취 업로드를 대기시킨 동안에도 통화를 조회하고, 업로드 완료 뒤 같은 번호에 녹취가 연결됨을 모의 저장소로 검증했다. 기존 PBX 시각 우선순위·조회 권한·기간 경계·페이지 총건수·분석 필터·오류 응답도 회귀 검증했다.
- 운영 PostgreSQL 17·Nginx·화면 자동 갱신·실제 통화·실제 S3 업로드는 이번 검증에서 실행하지 않았다.
