# 디버 접수 주소 설정

배포 환경에 `DVER_API_URL`과 `DVER_API_KEY`를 주입한다. 주소와 키가 모두 설정돼야 접수 요청을 전송한다.

설정한 HTTPS URL에 POST한다. 목적지에 필요한 포트와 경로는 전체 URL에 포함한다. `X-API-Key` 헤더, JSON 요청·응답 검증, 10초 제한과 재시도 정책을 유지한다. 결제 후 접수와 관리자 최종 접수, 자동·수동 재시도는 공통 `DverClient`를 사용한다.

주소를 전환할 때는 배포 환경변수를 변경한 뒤 백엔드 컨테이너를 재생성한다. 최종 접수 실패 주문은 연결을 확인한 후 관리자 재시도 절차를 따른다.
