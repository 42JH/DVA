# 디버 접수 주소 변경

2026-11-10 사용자 전달 기준으로 디버 접수 목적지를 변경한다.

```dotenv
DVER_API_URL=https://purple-wood-25a4.summer2.workers.dev
```

위 URL 자체에 POST한다. 별도 포트나 `/webhook/parcel` 경로를 덧붙이지 않는다. 기존 DVER_API_KEY와 X-API-Key 헤더, application/json, 요청 본문·응답 검증·10초 제한·재시도 정책은 유지한다. 결제 후 접수·관리자 최종 접수·자동/수동 재시도는 기존 공통 DverClient를 통해 이 설정을 사용한다. 프론트·AI가 호출하는 백엔드 API의 URL과 계약 변경은 없다.

백엔드 기본값·환경변수 예시·개발/운영 Compose 기본값을 동일하게 변경했다. 명시적인 DVER_API_URL 환경변수는 기본값보다 우선한다.

## 운영 반영

운영 `/home/ubuntu/dva-deploy/shared/.env`에 기존 주소가 설정돼 있으면 위 값으로 변경하고, 기존 배포 절차로 백엔드 컨테이너를 재생성한다. 파일 저장이나 기존 컨테이너 restart만으로 실행 환경변수는 갱신되지 않는다. DVER_API_KEY는 기존 값을 유지한다. 운영 환경 파일 변경·컨테이너 재생성은 이 MR에서 실행하지 않았다.

기존 주문 상태와 최초 재시도 기한은 유지한다. 최종 접수 실패 주문은 연결 확인 후 기존 관리자 재시도 절차를 따른다. 이 변경으로 주문을 다시 생성하거나 결제를 다시 받지 않는다. 실제 운영 주문 POST는 검증 중 전송하지 않는다.
